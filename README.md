# pvz-Infra

Infrastructure for the `0b-ivan` Plants vs. Zombies browser-game stack.

This repository owns local integration and deployment configuration. Application source code remains in:

- `0b-ivan/pvz-game`
- `0b-ivan/pvz-backend`
- architecture documentation: `0b-ivan/pvz-docs`

The target runtime is K3s/Kubernetes. Docker Compose is used as the local integration layer.
